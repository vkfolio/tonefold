AI music composer · Windows · open source

Describe a song. Get every part, ready to edit.

Tonefold is a composer app. Tell Claude what you want and it writes chords, melody, bass and drums into a piano roll you can change note by note, hear straight away, and export as MIDI or audio. You don't need a DAW, but there's an optional plugin if you use one.

What it does

A composer that writes like a band and listens like an editor

Each part follows what's already there, section by section, with the whole song in view. Everything it writes stays editable.

12 layer kinds

Composes layer by layer

Melody first? It fits chords to it. Chords first? It writes a melody over them. Bass, drums, pads, arps, plucks, counter-melodies, harmonies, sub and percussion follow.

humanize

Plays like a person

Repeats are new performances, not copies. Each style has its own groove and pocket, and sustained parts get swells, sustain pedal and 808 glides.

General MIDI

Sounds right away

A built-in synth means you hear the song before you choose a single instrument. Switch sounds per layer.

piano roll

Edit by hand

Draw, move and resize notes, set velocity, work in drum lanes and scrub the playhead. The composer sees your edits on its next turn.

.mid · .wav · stems

Take it anywhere

Export MIDI, a stereo mix and one WAV per layer, or drag a layer straight onto a track in your DAW.

CLAP · VST3

Optional DAW plugin

The same composer runs inside your DAW, follows its transport and sends live MIDI to your instruments. Tested in FL Studio.

Producer mode

It shows you the plan before it writes

For bigger changes, the producer reads your session and proposes a plan: key, tempo, form, and exactly which layer in which section each step will touch. Nothing changes until you approve it.

Four specialists, each in their own lane

Harmony and form, melody and topline, rhythm section, arrangement and mix. Each one can only write its own layers, so a step can't quietly rewrite your melody.

Approval is enforced by the app

Approving isn't a polite request in a prompt. Until you press Approve, the producer can't run any tool that writes.

One click to undo a whole run

A producer run makes more changes than undo can hold, so the session is marked first and Revert puts everything back.

How it works

A native app with an agent beside it

The editor, generators and synth are Rust and run without the internet. The composer is a small Node sidecar built on the Claude Agent SDK. It edits your session only through the app's tools.

Works without the composer. Generation, playback, editing and export need neither Node nor a model. The composer is there when you want to talk to it.

Your choice of model. Use your Claude login, or run on an Ollama model on this PC or another machine on your network. Each keeps its own conversation.

Drive it from outside. A command-line tool and a skill file let Claude Code, Claude Desktop or Codex compose Tonefold songs too.

Install

Three steps, no admin prompt

  1. Download the release

    Get the latest zip from GitHub Releases and unzip it anywhere.

  2. Run the installer

    It installs the app under your user profile and downloads the built-in sounds once (31 MB).

    powershell -ExecutionPolicy Bypass -File scripts\install.ps1

  3. Open Tonefold

    Start it from the Start Menu. For the chat composer, install Node.js 20+ and sign in to Claude Code, or point it at an Ollama server.

Want it inside your DAW?

Add the CLAP and VST3 plugins. This step asks for one administrator prompt, because plugins go in the system folders DAWs scan.

powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Plugins
  • Rescan plugins in your DAW and look for Tonefold.
  • FL Studio is the tested host; prefer the CLAP build there.
  • Other CLAP/VST3 hosts should work. Tell us how it goes.

Prefer to build it yourself? See building from source.

Open source

Free, GPL-3.0, built in the open

The engine, the app, the plugin and the composer's prompts are all in the repository. Bug reports, genre knowledge and new generators are welcome.

Do I need a DAW?

No. The app composes, plays and exports on its own. The DAW plugin is optional, for people who want the composer next to their own instruments.

What does it cost?

Tonefold is free. The chat composer uses your own Claude login, so any cost is whatever your Claude plan charges, shown per turn in the app. With Ollama it costs nothing beyond your hardware.

Can it run without the cloud?

Yes. Everything except the chat composer runs offline, and the composer can use an Ollama model on your own PC or another machine on your network.

Is there a Mac version?

Not yet. Tonefold is Windows-only today. macOS is on the roadmap; the engine already builds there.

Who owns what I make?

You do. The GPL covers Tonefold's code, not the songs you make with it, and Tonefold claims nothing over them.
